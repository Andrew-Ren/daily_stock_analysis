# 选股结果解释层

Web 选股结果展开态新增“为什么入选”和“为什么现在”两块解释，用于把候选股票从排序列表升级为可复核的研究入口。

## 为什么入选

优先按以下来源生成：

1. LLM thesis 或后端 reason。
2. 排名前三的本地因子分，例如估值、流动性、动量。
3. 后置分析标签，例如价值质量、受控反转、趋势动量。
4. LLM 风格匹配说明。

没有上述字段时，回退到原有摘要逻辑。

## 为什么现在

优先按以下来源生成：

1. LLM 催化因素。
2. DSA 新闻标题或摘要。
3. DSA 事件标题或摘要。
4. 当日涨跌幅。
5. 成交额。
6. LLM 关注项。

没有上述字段时，显示等待新的价格、消息或事件确认。

## 边界

- 本次不改 `/api/v1/screening/*` 响应结构。
- 原有排序依据、风险、摘要、智能判断、新闻、事件和进一步深度分析入口保持不变。
- 当前解释是前端派生字段，后续可由后端输出结构化 `why_selected` / `why_now` 替换。

## 后续扩展

- 结合 ResearchArtifact 生成候选投资假设和失效条件。
- 结合热点题材详情，把“为什么现在”拆成题材发酵、个股异动和消息催化三层。
- 结合组合页，把“为什么入选”补充为是否符合当前账户风险预算。
